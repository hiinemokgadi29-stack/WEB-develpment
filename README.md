## 2\. Project Overview

The Sephaphoshe NPO Website is a five-page responsive web application developed for the **Sephaphoshe Old Age & Day Care Centre**, located in Ga-Mothapo, Limpopo, South Africa.

The purpose of the website is to establish a professional online presence for the organisation, communicate its services and community activities, and attract potential donors, corporate social investment (CSI) partners, government departments and community volunteers.

The website provides information about the organisation's background, services, infrastructural needs and contact information. It also includes an enquiry platform through which potential funders and other interested parties can communicate with the organisation.

The project was developed using HTML5, CSS3 and JavaScript, with an emphasis on semantic HTML structure, responsive web design, accessibility, user experience and search engine optimisation.

## 3\. Website Goals and Objectives
